### 🌍 Federated Multi-Agent RAG (Soliga Language AI)
> *Privacy-preserving multilingual AI for low-resource languages*
```
├── 🤖 LangGraph multi-agent orchestration (Router → RAG → Refinement)
├── 🌱 FedAvg Federated Learning with LoRA-style weight compression
├── 📦 ChromaDB + Ollama for fully local RAG pipeline
└── 🔍 Custom PyTorch InfoNCE bilingual alignment loss
```

### 🤖 VMHA Dialogue Agent
> *GPT-2 multi-head conversational agent with RL optimization*
```
├── 🧠 Parallel RAC, Emotion & Valence-Arousal prediction heads
├── 🎯 PPO optimization with composite reward (ROUGE + BERTScore + DA/Emo accuracy)
├── 📊 End-to-end dialogue context encoding pipeline
└── 🔄 Policy update via clipped surrogate objective
```

### ⚖️ Legal LM
> *LangGraph multi-agent legal triage system*
```
├── 🔍 Small2Big RAG retrieval with AIR/SCC citation validation
├── 📡 Arize Phoenix observability for full pipeline tracing
├── 🤖 Local Ollama LLM with LangGraph supervisor orchestration
└── ✅ Regex-based citation verification (e.g. Kesavananda Bharati AIR 1973)
```
